# Automatic Backup Script

## About
A Bash script that creates a compressed backup of a directory.

## Usage
Run the script with the directory to back up:

    bash backup.sh /path/to/directory

Example:

    bash backup.sh ~/linux-portfolio/01-basics

## Backup Location
Archives are saved in:

    ~/linux-backups

## Skills Practiced
- Bash scripting
- Command-line arguments
- Directory validation
- Variables and date formatting
- Creating compressed archives with tar
- File permissions and error handling
