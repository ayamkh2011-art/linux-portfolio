# System Information Report

## About
A beginner Linux project that displays basic system information
using a Bash script.

## Information Displayed
- Current date and time
- Current username
- Hostname
- Linux kernel version
- Disk usage
- Memory usage

## How to Run
Make the script executable:

    chmod +x system_info.sh

Run the script:

    ./system_info.sh

## Skills Practiced
- Bash scripting
- Running Linux commands inside a script
- Using command substitution and variables
- Checking command availability
- Viewing disk and memory information
- File permissions
